# 🎮 Top Down RPG

Projeto de um jogo **Top Down RPG** desenvolvido na **Unity 6** utilizando **C#**.

Este projeto está sendo desenvolvido como parte dos estudos realizados no curso **Oficina Indie**, ministrado por **André Young**.

## 🚀 Tecnologias

- Unity 6
- C#
- Git
- GitHub

## 📚 Objetivo

O objetivo deste projeto é colocar em prática conceitos de desenvolvimento de jogos, programação em C#, arquitetura de projetos e mecânicas comuns de RPGs top-down.

## ✨ Funcionalidades

- Sistema de movimentação
- Sistema de combate
- Inventário
- Loja
- Inimigos
- Coleta de itens

> **Observação:** O projeto está em desenvolvimento e novas funcionalidades serão adicionadas conforme o andamento do curso.
